## 第零章｜業界演講用 / Chapter 0 | Industry Talks

第零章（chapter-00/index.html）收錄業界演講與企業內訓用的活動與線上個案，不屬於「大數據與資料科學」課程內容，但與各章同一層、列在首頁。目前用於「團隊溝通與衝突溝通」與「AI 導入專案規劃與策略」課程：
Chapter 0 holds activities for industry talks and corporate training. They are not part of the course content but sit at the same level as the chapters and are listed on the home page.

- 衝突風格自評位於 chapter-00/activities/conflict-style/（單一檔案、不連外部資源）：20 題 DUTCH 量表，作答後在手機上計分並畫出雷達圖，答案不會上傳。原本的網址 conflict-style/ 保留為轉址頁，舊的 QR Code 仍可使用。
- DISC 動物風格測驗位於 chapter-00/activities/disc/（單一檔案、不連外部資源，插圖為內嵌 SVG）：10 題四選一，選項 1–4 依序計為 D、I、S、C。最多的一型為結果；兩型並列最高時顯示兩種動物；三型以上並列時顯示變色龍。結果頁有四型題數長條圖與四種風格一覽（重事／重人 × 步調快／慢）。右上角可切換中文與英文，?lang=en 或 ?lang=zh 指定語言。答案只存在學員自己的瀏覽器（localStorage），不會上傳。
- 企業AI準備度自我檢核位於 chapter-00/activities/ai-readiness/（單一檔案、不連外部資源）：六個構面（策略與領導、資料、技術與基礎設施、人才與技能、流程與組織、治理與風險），題目文字與講義相同，各以 1–5 分作答。結果頁顯示六構面平均與三段判讀（平均 ≤ 2 先補數位化與資料基礎；2～3.5 選一個單點流程做 PoC；≥ 3.5 可規劃跨部門擴散，門檻沿用講義）、雷達圖、該段的建議步驟，以及優先補強構面（1–2 分的構面依分數由低到高最多列三個；沒有 2 分以下時列最低分構面）的具體做法；平均達 2 以上但有構面在 2 分以下時另提醒短板。建議文字皆整理自課程講義。右上角 A−／A+ 調整字體，結果可一鍵複製。答案只存在學員自己的瀏覽器（localStorage），不會上傳。
- 個案閱讀：沐鼎鮮鍋位於 chapter-00/cases/mu-ding-hotpot/（單一檔案、不連外部資源，插圖為內嵌 SVG）：個案全文依授課講義原文分四段呈現，未經增刪；每一句是一個步驟，讀到哪一句，旁邊的示意圖就畫到哪一步，最後列出兩題討論問題。版面與 ABC 衛浴生活館相同：電腦上圖在左、文字在右；手機上圖固定在上方、文字在下方。右上角 A−／A+ 調整字體大小，「聚焦」只亮出目前這一句；可捲動、點句子、按右下角箭頭或簡報筆（↓／→／空白鍵／PageDown）前進。字體大小與聚焦設定存在學員自己的瀏覽器。
- ABC 衛浴生活館與第三章共用 chapter-03/cases/abc-bath-living/，第零章的連結與 QR Code（assets/qr/abc-bath-living-zh.png）帶 ?lang=zh，直接開啟中文版。

## 網站架構 / Structure

首頁為 index.html，第零章為 chapter-00/index.html，第一章為 chapter-01/index.html，第二章為 chapter-02/index.html，第三章為 chapter-03/index.html。

第一章的四個互動遊戲分別位於 chapter-01/games/ 下的 titanic、predpol、decision-lab、airline-survival。
titanic、decision-lab 的 HTML 與提供的原始 ZIP 完全一致，保留原有遊戲邏輯與語言功能。
airline-survival 保留原有遊戲邏輯與語言功能，另外加上：右上角 A−／A+ 調整字體大小（設定存在學員自己的瀏覽器）；手機版（寬度 700px 以下）的「執飛／維護」改為左右並排的大按鈕，回合、現金、已選架數與「派遣機隊／下一回合」按鈕固定在畫面底部，未選完時會標出還沒選的飛機並捲到該處，派遣時自動捲到結果區。
predpol 另外加上手機與小平板的版面（螢幕寬度 850px 以下，或手機橫放）：保留地圖（街道、河流、道路、警察局與各區的相對位置），各區文字精簡，紅區會整區變紅並顯示紅色標記；計分板固定在上方，派警車按鈕移到地圖上的警察局，所選區域的資料固定在下方；計分、計時與模型規則的程式沒有更動，桌機版面維持原樣。頁首與每張說明／結果卡片上有 A−／A+ 可調整字體大小（設定存在學員自己的瀏覽器）；桌機上放大字體時，地圖會跟著加高，讓各區文字有空間。

第二章有四個活動：旅人人格測驗位於 chapter-02/games/traveler/，檔案與提供的原始 ZIP 完全一致（來源與許可說明見該資料夾的 README.md 與 sources/），右上角可切換中文與英文；
最後一張優惠券位於 chapter-02/games/last-coupon/，右上角可切換中文與英文；
動態標籤實戰位於 chapter-02/games/dynamic-labels/，中英文同時顯示；
「直接用，還是先問為什麼？」位於 chapter-02/games/apply-or-ask-why/，中英文同時顯示，對應講義 Causation vs. Correlation 一頁，約 10 分鐘。

最後一張優惠券的遊戲本體是 index.html，內含三段程式：ENGINE（顧客模擬模型，參數集中在開頭的 P 物件）、COPY（全部中英文文字）、APP（畫面與流程）。
網址後加 ?seed=7 可換一批模擬會員，?lang=zh 或 ?lang=en 指定首次開啟的語言，?reset=1 清除該裝置上的進度。
模型邏輯與建議的時間分配寫在遊戲結算頁最下方「給授課教師的說明」。

最後一張優惠券的班級模式（教師看各組分數與回答、由教師開放下一季）：
- 教師頁：chapter-02/games/last-coupon/teacher.html。在這裡自訂班級代碼、取得學生用的網址與 QR Code、查看各季各組的決定、回答與四個數字，並按「開放」讓各組進入下一季。
- 學生從 `?class=班級代碼` 的網址進入才會啟用班級模式；直接開啟遊戲則是單機模式，不會送出任何資料。
- 資料存在教師自己的 Google 試算表。後端程式是 backend/Code.gs（全站共用），貼進該試算表的 Apps Script 後部署為網頁應用程式（執行身分：我；誰可以存取：所有人）。詳細步驟寫在教師頁。
- 部署後的網址（結尾 /exec）填在 assets/class-sync.js 的 syncUrl（last-coupon/config.js 會讀這個值）。留空時班級模式不啟用。
- 修改 Code.gs 之後，要在 Apps Script 重新「管理部署作業 → 編輯 → 新版本」才會生效。

店長的一天：RFM 足測鞋店位於 chapter-02/games/aso-store/（單一 index.html，無外部資源），改編自講義 p.34–37 的阿瘦個案。經營 10～12 月一季，右上角倒數 5 分鐘（第一位客人進店開始計時，對話框開著也不停；時間到立刻結算），10 位會員每次隨機 1～3 位進店、各來 1～3 次；上方顯示日期、倒數、營業額／目標（NT$30,000）與每位會員的忠誠度條。網址加 ?sec=180 可改成 3 分鐘，業績目標會等比例調整。目標是達成業績並讓忠誠客戶（忠誠度 70 以上）多於開店時的 3 位。客人頭上有滿意度，等太久或服務錯誤會下降，歸零即生氣離開、忠誠度 −35；忠誠度低於 30 就不再來。手機與直向螢幕使用直向門市＋底部面板、點地板走路；寬螢幕使用橫向門市＋側欄，也可用方向鍵或 WASD。右上角可切換中文與英文。結束後有結算與五題討論題。

裝甲該裝在哪裡？位於 chapter-02/games/armor/（單一 index.html，無外部資源），對應第二章講義「正確解讀數據 & 問對問題」的二戰轟炸機彈痕例子（倖存者偏差）。流程：看返航飛機彈痕 → 選 2 片裝甲 → 100 架出任務 → 揭露被擊落飛機的彈孔 → 第二次選擇 → 3 題行銷資料倖存者偏差題 → 討論題。模擬使用固定亂數種子，同樣的選擇得到同樣的結果。右上角可切換中文與英文。

裝甲遊戲的課堂投票：教師頁是 chapter-02/games/armor/teacher.html，只要輸入教師密碼；每天自動成為一場投票（代碼 D+年月日），學生用教師頁上的網址或 QR Code 進入、填組名，第一輪、猜測、第二輪與行銷題的答案會自動送到 Google 試算表的「投票」分頁，教師頁每 4 秒更新長條圖與各組明細，也可以先隱藏結果。和最後一張優惠券、課堂即時問答共用同一個 Apps Script（backend/Code.gs，網址在 assets/class-sync.js）；更新程式碼後要在 Apps Script 部署「新版本」。沒有 `?class=` 的網址則照常單機遊玩，不送出任何資料。

第三章有一個個案閱讀頁：刷卡被拒：信用額度不足位於 chapter-03/cases/card-declined/（單一 index.html，無外部資源），呈現講義 p.10–14 國泰世華個案的英文全文（逐字照講義，不摘要），最後附 p.9 的兩題討論題。每一句是一個 <span class="s" data-st="N">，讀到第幾句，旁邊的示意圖就畫到第 N 步；手機上示意圖固定在上方、原文在下方捲動。預設英文，右上角可切換中文（中文為英文個案的逐句翻譯，存在程式內的 ZH_S 陣列，插圖文字放在各元素的 data-zh）；網址加 ?lang=zh 或 ?lang=en 指定語言。投影時可用簡報筆（PageDown）或 ↓／Space 逐句前進，Spotlight／聚焦會淡化其他句子，A−／A+ 調整字體。

第三章的第二個個案：個案：ABC衛浴生活館位於 chapter-03/cases/abc-bath-living/（單一 index.html，無外部資源），是虛構的教學個案，呈現講義 p.2–10 的中文原文全文（逐字照講義，不摘要），英文版為逐段翻譯；兩者都放在程式開頭的 CASE 資料，每段為 [第幾步, 中文原文, 英文, 中文螢光標示, 英文螢光標示]。每一段驅動旁邊示意圖的第 N 步。預設英文，右上角可切換中文；?lang=zh 或 ?lang=en 指定語言。最後是 p.11–13 的顧客旅程地圖活動：五個階段各選心情（2 到 −2）並寫原因，頁面畫出情緒曲線、加總體驗分數，接著是 p.12 的討論題；答案只存在學生自己的瀏覽器（localStorage），不會上傳。p.12 的「機會／命運」卡未放進網頁，由教師在課堂上進行。

首頁及各章頁面支援繁體中文 / English 切換。

## 更新與部署 / Updates and deployment

## 課堂即時問答 / Live Class Q&A
- 學生頁：qa/（掃教師頁上的 QR Code，只要輸入名字）；教師頁：qa/teacher.html（只要輸入教師密碼，這台電腦會記住）。課程首頁也有入口。所有人共用同一個問答室；網址加 `?class=代碼` 可以另開一間。
- 教師密碼：第一次登入教師頁時輸入的密碼（至少 4 個字元）就成為教師密碼，存在試算表「設定」分頁 B2，可直接修改。課堂問答、裝甲遊戲教師頁、最後一張優惠券教師頁共用這組密碼。
- 教師頁可以建立題庫（單選、多選、簡答、文字雲、1–5 分評分），按「發布」後學生畫面自動換成這一題；回答每 3 秒更新成長條圖、平均分數、文字雲或簡答列表。可以關閉作答、隱藏結果、顯示或隱藏名字、投影模式、放大 QR Code。每次發布都是一輪新的作答，舊的回答留在試算表。
- 全站課堂互動共用一個後端：backend/Code.gs（Google Apps Script），網址只寫在 assets/class-sync.js。試算表分頁：投票（所有回答）、問答發布（各班目前的題目）、題庫、設定（教師密碼）；最後一張優惠券另外使用「各組提交」「放行」。
- 第一次設定：個人 Gmail 開試算表 → 擴充功能 → Apps Script → 貼上 backend/Code.gs → 部署為網頁應用程式（執行身分：我；存取：所有人）→ 授權 → 網址寫入 assets/class-sync.js。之後更新程式碼：管理部署作業 → 編輯 → 新版本，網址不變。
